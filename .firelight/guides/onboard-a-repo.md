1. Copy the prompt from the ⓘ overlay ("Add a repo"), or run
   `firelight skills onboarding`, or use the MCP prompt `onboard_repo`.
2. Give it to your coding agent in the repo.
3. Review the pull request it opens like code, and merge it.
4. Add the repo as a source in Firelight's config.
